개인정보처리방침 · Privacy Policy

Another Us Uploader (이하 "본 도구") · 최종 수정일 / Last updated: 2026-10-10

1. 본 도구에 대하여 / About this tool

본 도구는 어나더어스(Another Us) 채널 운영자가 직접 제작한 영상을 운영자 본인의 YouTube 채널에 업로드하기 위한 내부용 프로그램입니다. 일반 사용자에게 제공되는 서비스가 아니며, 운영자 본인 계정에만 사용됩니다.
This tool is an internal program used only by the operator of the Another Us channel to upload the operator's own videos to the operator's own YouTube channel. It is not offered to the public.

2. YouTube API 서비스 사용 / Use of YouTube API Services

본 도구는 YouTube API 서비스를 사용합니다. 본 도구를 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google 개인정보처리방침이 적용됩니다.
This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service; the Google Privacy Policy applies.

3. 접근하는 정보 / Information accessed

  • 운영자 YouTube 채널의 기본 정보(채널 ID, 이름) — 올바른 채널에 업로드하기 위해 사용합니다.
  • 본 도구가 업로드한 동영상의 메타데이터(제목, 설명, 공개 상태, 처리 상태) — 업로드 확인과 예약 공개에 사용합니다.
  • OAuth 인증 토큰 — 운영자 PC의 운영체제 자격 증명 저장소(Windows Credential Manager)에만 저장됩니다.

The tool accesses the operator's channel ID and name, metadata of videos it uploads, and an OAuth token stored only in the operator's computer credential store.

4. 이용, 공유, 보관 / Use, sharing, storage

수집한 정보는 업로드와 업로드 상태 확인에만 사용하며, 제3자에게 판매하거나 공유하지 않습니다. 광고나 분석 목적으로 사용하지 않습니다. 업로드 기록(동영상 ID, 업로드 시각, 승인 기록)은 운영자 PC에 보관되며, 운영자가 언제든 삭제할 수 있습니다.
Data is used only to upload and check uploads; it is never sold or shared with third parties or used for advertising. Upload logs stay on the operator's computer and can be deleted at any time.

5. 접근 권한 철회 / Revoking access

Google 보안 설정의 타사 앱 접근 권한 페이지에서 본 도구의 접근 권한을 언제든 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 작동하지 않으며, 운영자는 PC에 저장된 토큰을 삭제합니다.
You can revoke this tool's access at any time via the Google security settings page.

6. 문의 / Contact

문의는 어나더어스 YouTube 채널 @anotherusworld을 통해 남겨 주세요. 전용 문의 이메일은 개설 후 이 페이지에 추가합니다.
Please contact us via our YouTube channel @anotherusworld. A dedicated contact email will be added here.
